Mono text chip for tags / statuses / technical labels. Square-crisp, never a pill.

```jsx
<Badge variant="outline">GPL-3.0</Badge>
<Badge variant="spark" dot>Live</Badge>
<Badge variant="ink">v2.4</Badge>
```

Variants: `outline` · `ink` · `accent` (magenta) · `spark` (magenta hairline). `dot` adds a status dot.
