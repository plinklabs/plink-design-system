Flat instrument-panel button — `primary` is the single magenta spark per screen; use `ghost`/`outline` for everything else.

```jsx
<Button variant="primary">Browse the products →</Button>
<Button variant="outline">View on GitHub</Button>
<Button variant="ghost">★ Star</Button>
```

Variants: `primary` (magenta), `secondary` (ink), `outline` (hairline), `ghost` (mono link).
Sizes: `sm` · `md` · `lg`. Props: `block`, `as`, `href` (auto-renders `<a>`).
